# HSR Analysis

崩铁伤害工作台：双主题 Web UI、遗器属性编辑、4.6 数据快照和自研战斗规则模拟器。所有页面本地运行，离线成品可直接用浏览器打开。

已接入数据库全部 98 名角色的执行模块，支持四人换队、角色资源、追加攻击、忆灵、独立行动事件、欢愉阿哈行动条与多波次。战斗页默认近似试算，已知不完整机制在队员卡片和结果中标注；严格验算仍阻止已知缺口。**可运行不代表所有机制精确复现，完整实战录像对拍尚未完成。** 当前仍保留遐蝶、长夜月、昔涟、火花、银狼 LV.999 共5名角色的严格阻断；已接入的社区近似与其余覆盖情况见[全角色机制覆盖](docs/全角色机制覆盖.md)。

遗器支持六个部位、二至五星、强化等级和逐档副词条次数。合法配装自动进入面板；手动录入会暂停自动覆盖。条件套装与光锥效果在增益管理中核对。

伤害计算按技能描述的总倍率与逐项重复次数计算。随机弹射命中目标的次数可单独指定，动画段数不会再次放大总倍率。

## 开发与验证

Node.js 24+、Python 3.10+；无需 npm install。

```sh
npm start
npm test
npm run build
npm run test:mutations
```

开发服务仅监听 127.0.0.1:8777，首页为模式选择；/calculator 与 /battle 为独立开发入口。打包产出模式选择、双主题计算器、浅色计算器与独立四人战斗页面，共用公式与数据，队伍配置互不覆盖。

## 更新数据

```sh
python _scripts/update_database.py --version 4.6
npm run build
```

也可运行 `npm run update` 自动发现正式数据目录。JSON 校验、清单哈希、完整性检查失败时不激活新数据库；历史数据库保留。新版本仍需核对新增角色与机制，版本目录存在不代表机制已实现。

## 结构

`core/`：面板、词条、技能、增益与伤害纯函数；`ui/`：双主题界面；`simulator/`：行动轴和事件引擎；`data/`：数据库、词条表与来源；`annotations/`：人工校订；`_scripts/`：构建、更新与回归检查。
