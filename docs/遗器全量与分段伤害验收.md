# 遗器全量规则与分段伤害（本地验收）

本轮覆盖当前 4.6 数据库里的全部 **62 套：外圈 101—134 共 34 套，内圈 301—328 共 28 套**。可选二件、四件、二加二；套装描述随配装显示，也可以展开完整目录查看。数值和来源记录在 `data/combat/source_evidence.json`，参数契约由 `_scripts/build_strict_evidence.py` 生成。

## 结算方式

| 类型 | 接入的条件与行为 |
| --- | --- |
| 常驻、属性、盾量 | 治疗、攻防生命、速度、暴击、暴伤、效果命中/抵抗、回能、击破、各属性增伤、护盾量；二件与四件不互相覆盖 |
| 施放与回合 | 冰套终结前暴伤、雷套战技前攻击、火匠下次攻击、学者下次战技、翔鹰拉条、信使/钟表匠不可叠光环、司铎叠层、领航员入场/战技增层与回合开始/终结后减层、异端普攻 |
| 追击 | 大公逐次命中叠攻击、下次追击清旧层；都蓝按全队每次追击加功勋，第五层当次生效；勇烈强化终结技；千星在追击前加攻击 |
| 受击、生命、治疗 | 拳王每次攻击或受击叠层；莳者受击/消耗生命触发，护盾吸收不取消受击；铁卫低血回复；甘霖排除本人及自己的忆灵、每个本人回合限一次；隐士只认本来源护盾 |
| 目标状态 | 废土的减益/禁锢，系囚按 DOT 数量穿防（纠缠不冒充 DOT），先驱二/三减益档位及本人施加减益翻倍，名冶减防条件与助燃重触发限制 |
| 击破 | 怪盗破韧回能；铁骑区分击破 150% 和超击破 250% 阈值；铸炼宫火弱点命中；塔利亚速度条件。超击破需真实来源，不因装备铁骑自动产生 |
| 击杀 | 茨冈尼亚暴伤叠层封顶、跨波次保留；千星全队唯一常驻暴伤 |
| 面板与队伍条件 | 太空站、贝洛伯格、商业公司转换上限、萨尔索图/竞技场暴击门槛、格拉默速度档位、差分机首次攻击、仙舟/龙骨/匹诺康尼光环、露莎卡站位、出云同命途、蕉乐园、拾骨地、巨树、海隅、乐园在场人数、生研院入场能量上限 |
| 忆灵 | 显式 `memospriteOwner` 绑定，英豪在场速度/忆灵攻击暴伤、诗人/拾骨地/巨树的对应继承、救世主普攻战技后刷新生命与全队伤害、翁法罗斯唯一速度光环。龙灵等战斗事件召唤物不当成可选忆灵 |
| 欢愉与资源 | 魔法少女按实际累计获得笑点分档、卜者入场速度暴击和首次欢愉技唯一光环、伶人单体他人目标和好活当赏条件、朋克洛德首次达到 40%/80% 解锁暴伤；没有对应事件不自动触发 |
| 战技点与身份 | 过客入场回点；直播间同一自身回合累计消耗；坠星按正式脚本 `CharacterIDGroups.AstralExpress` 判断，不根据角色名称或阵营猜测 |

同时修复旧错误：**渊思寂虑的巨树提高治疗量，不提高攻击力**。对应测试改为按原文检查治疗量和攻击不变。

## 伤害展示

- 战斗页面大字显示**技能本体各段总和**，旁边小字列各段实际结算伤害。群攻同一动画段对多个目标的伤害合计为一段，悬停可查看各目标数值。
- 击破、超击破、刻律德菈等触发的附加伤害单列小字；“最近行动伤害”仍包含本次行动的全部触发伤害。其他队员的附加伤害不会冒充主施放者的技能本体。
- 回放中只读取当前位置以前的结算记录，未结束时显示“已结算伤害”；不会显示未来段的数字。零伤害辅助技能显示本次为零，不沿用上一个技能。
- 单次计算器对已有原始动画权重的技能也显示分段，采用当前同一面板拆分，并明确标注。Archer 终结技为前 14 段各 4%、末段 44%；战斗页面逐段实际计算，能反映中途变化。
- 自定义动作可通过 `hitShares` 提供明确的动画比例；没有来源的技能不会擅自均分或伪造段数。

## 证据与验证边界

固定数据来源：[DimbreathBot/TurnBasedGameData@312b4597](https://github.com/DimbreathBot/TurnBasedGameData/tree/312b4597691e0a29cf9828a15b592757dba86949)，以及已有 nanoka 4.6 数据库。新增读取 Equip30/31/33/34/36/37/40/41/43/44 的遗器事件与全局角色分组配置；只读取 JSON，没有执行外部脚本。

**133「戏梦点星的伶人」、134「贪噬禁果的异端」本次未在固定版本找到对应触发脚本**，已按数据库文案实现，配装页面保留“时序尚待交叉核验”说明。其余套装的具体触发仍以源码和测试所列事件范围为准，不把程序回归称为所有套装已完成游戏逐项实测。

忆灵/欢愉的套装钩子已实现，**不代表这些体系的全部角色技能也已实现**。严格模式仍只允许登记的四人角色、光锥与敌人行为；不会为了让套装触发而给四人队凭空添加忆灵、笑点或欢愉技。自定义 JSON 的 `memospriteOwner`、`laughter`、`punchline`、`hpConsume` 与 `superBreak` 用于明确来源的规则场景测试。四人原生技能不能直接篡改系数获得超击破。

验证命令：`npm test`、`python _scripts/build_strict_evidence.py --check`，以及单次/战斗 HTML 构建。新增 `_scripts/test_relic_runtime.mjs` **33 组**检查，含 62 套逐套应用运行、条件/层数/来源/阈值、十五段求和、群攻归段、回放前缀、导出复现与单次结果展示。已有公开实例 18 项保持通过。个人游戏锚点仍为空，该项跳过；完整队伍实战对拍状态见《公开实例验证报告》。

本轮仅更新本地验收文件，未提交或推送 GitHub。
