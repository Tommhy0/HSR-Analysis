# 自动战斗手法复核（2026-10-21）

用户指出遐蝶死龙没有正确连续喷焰。本轮以线上原作者攻略和本地固定版本技能脚本核对自动操作，修复已确认的选择错误。保留手工 rotation、turnPlan、actionPlan 的优先级。

## 遐蝶与蝶风三昔

原实现将死龙一次循环预估为最多4次重复伤害。二魂的2次免耗血没有增加次数，途中回复生命也不能延长连喷；最后一喷之前就打出晦翼，而且没有立即退场。

现在每喷单独结算10段伤害和攻击后的机制，连续喷焰共用一个回合，不多花AV，不递减回合增益，不在中途插入自动终结技。每喷重新读取实际生命和炽意；低血最后一喷之后才结算晦翼、治疗和退场。标准满血场景为E0四喷、E2六喷；途中恢复生命时可延长，敌人全灭时立即停止。新召唤会清除上条死龙的收尾标记。

依据：[紫喵Azunya的遐蝶机制攻略](https://www.taptap.cn/moment/658968231964315244)，特别是连续焰息、每喷10段、二魂免费2喷和最后一喷后自爆的说明。数值仍沿用工程当前固定数据库，本轮没有另改技能倍率。

还发现二魂首个强化战技的30%新蕊被错误转成死龙回血。本地 `Avatar_Castorice_00_Ability.json` 中 Skill21调用 `Avatar_Castorice_AddSpecialSP`，该模板直接 `ModifySpecialSP` 且 `IgnoreBlock=true`；已改为死龙在场时也直接保存新蕊，为下一次召唤充能，并且每次召唤只返还一次。

昔涟在蝶队自动献诗改为长夜月→遐蝶；两人的永久诗篇生效后使用自身攻击分支。阿格莱雅队不会用紧接着的第二个大招覆盖尚未消费的浪漫。涟漪形态使用强化普攻。界面和配置导入新增 `poemStrategy: fixed` 可固定献诗给辅助目标；默认 `auto` 按上述队伍规则分配。

依据：[璐洛洛昔涟攻略的粉毛战舰实战、浪漫之诗及强化普攻说明](https://www.kocpc.com.tw/archives/619921)。这是一套通用自动策略，没有实现该文所有短轴穿插与蓄能细节。

## 成品网页补充验证

重新生成并实际打开单文件网页时发现：extra/index.mjs将四张注册表写在同一条export const中，而静态打包器只收集首个导出，导致成品页读取遐蝶配置时报错，角色运行工厂也会遗漏。现已拆为四条显式导出，并给战斗构建自检加入“读取四名记忆角色的保存配置并执行死龙行动”的成品路径，避免默认四人队自检漏报。连喷回放标签也改为通用的“同回合连续行动”。成品页已通过实际读取、运行及单步回放，结果116.33 AV，与源码运行一致。
