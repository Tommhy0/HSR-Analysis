# 自然语言配置与公开视频验收

日期：2026-10-16。改动保留在本地，尚未提交或推送 GitHub。

## 网页与个人技能

四人战斗页面顶部新增“AI 配置导入 · 自然语言配装”。支持 JSON 文件、粘贴和 `#hsr-config=` 导入链接，先校验与预览，应用后可撤销。可以修改一名或四名角色，未指定的队员、敌人与场景保留。自然语言由使用 `hsr-config` 技能的 AI 解析；离线网页不调用在线模型，也不将任意自然语言冒充已解析配置。

技能已同时安装到：

- `C:\Users\ASUS\.agents\skills\hsr-config`
- `C:\Users\ASUS\.claude\skills\hsr-config`

源码为 `skills/hsr-config/`。两端的 SKILL.md、版本文件、参考文档和脚本已逐文件比较 SHA-256，公共文件一致。覆盖不同旧文件前会备份，不删除未知文件或专用配置。两端技能校验均通过，Claude 端安装后的脚本也已实际编译示例。

可以这样说：

> 用 hsr-config 配置我的四人队：红花刻龙全 01，强化花火风翁，局外 160 速、200 暴伤；红A 量子都蓝，盾丹隐士露莎卡，刻律风露，三拐红A。其他配置沿用，直接导入当前战斗网页。

完整示例在 `data/validation/config-language-example.json`，编译产物在 `outputs/自然语言导入示例.hsr.json`。这是功能验收用参考队补丁，不是用户实测配装或录像配装。

局外详情面板与引擎输入区分处理：登记的光锥、遗器常驻属性先扣除，运行时由装备机制加入一次。例如局外花火 200% 暴伤、S1 游戏尘寰，导入输入为 168%，运行后恢复 200%。不会扣除只在入场或战斗中生效的额外加攻。诗人四件的速度分档和未登记光锥不自动反推。

`龙、丹恒、2速2速` 等有歧义时不能随便映射；`00` 只表示不带专武，不能推断没有其他光锥。历史版本、未解决项、非法副词条和当前未实现的角色机制会阻止导入，不降低严格模式以求通过。
