# 严重问题修复记录（2026-10-21）

本轮修复此前复现的崩溃和数值结算问题，并更新可直接使用的 HTML 成品。

## 修复内容

1. **忆灵面板递归崩溃**：记忆开拓者的暴伤转换、阿格莱雅的速度转攻击遵守原始面板读取标记；忆灵继承遗器条件属性时只读取必要属性，并排除循环转换。普通战斗中的转换与光环仍生效。
2. **白厄重复变身造成负伤害**：卡厄斯兰那形态禁用终结技，自动入队、回放可用技能和实际执行保持一致；防止倒计时重叠。手动操作轴指定禁用中的终结技会明确报错，避免反复入队。
3. **忆灵伤害漏计及回放阵营错误**：结果保留运行时单位阵营与召唤归属。总伤害计入忆灵，队员贡献归入召唤者；回放累计曲线使用相同归属。旧日志通过召唤事件恢复归属。我方内部伤害不计入对敌输出。
4. **超击破漏算击破效率**：共享公式与大丽花对未击破目标的公式均包含效率；攻击期间的临时效率保留到攻击后的超击破结算，避免流萤清除临时增益后忘归人少算。
5. **击破专属增益未进入最终数值**：同谐开拓者行迹作为其自身超击破来源的独立倍率，忘归人 E4 作为击破专属增伤。两者分别结算，避免混入通用增伤，也避免影响其他超击破来源。
6. **阮·梅瞬时击破附伤误作持续伤害**：天赋与残梅绽使用独立的击破附加伤害分类，保留击破增益，避免吃到桑博持续伤害易伤或触发持续伤害监听。
7. **同谐女主弹射削韧翻倍**：单次弹射由 30 改为 15 个内部韧性单位，与男主及原始技能脚本一致；E0 首次战技单目标合计削韧 120。
8. **桑博终结技在单次计算器中丢失直伤**：提取器按伤害所在分句判断时机，后续“持续伤害提高”描述不会将前面的直伤标记为延迟伤害；真正的回合持续伤害仍保留延迟分类。

回放界面同时补充“击破附加伤害”和“超击破伤害”的中文名称。

同谐开拓者的来源倍率另与 [Fribbels 实现](https://github.com/fribbels/hsr-optimizer/blob/a44c5d3ae2f1ed5907055a16c264bdc2392cf131/src/lib/conditionals/character/8000/TrailblazerHarmony.ts) 交叉核对；各角色参数继续读取本地技能、行迹和星魂数据。
