# 四人专武队严格模式 · 本地验收

本轮公开实例验证与多波次更新见 [公开实例验证报告](公开实例验证报告.md)。

2026-10-16。当前实现针对花火、丹恒•腾荒、Archer、刻律德菈及四人的专属光锥；本轮尚未提交或推送 GitHub，等待用户验收。

## 打开与配置

直接打开根目录的 `严格战斗_验收版.html`。页面自动运行四人参考队，暂停在 Archer 首次十五段终结技结算处，能看到大字总伤、小字分段、行动条与龙灵。也可用普通入口 `战斗模拟器.html`。

默认 E0S1、强化花火、四人启用秘技，三名辅助的战技目标均为 Archer。星魂尚未由用户指定，因此 E0 是验收默认值；参考面板也不是用户实际账号面板。原版 / 强化版花火、星魂、技能基础等级、光锥叠影和每名辅助的目标均可单独修改。

手动面板输入角色 / 光锥白值、已解锁的固定属性行迹、遗器主副词条后的常驻属性；已选择光锥的被动、已选择套装的效果和战斗增益由引擎另行加入。把这些被动再次录入手动面板会重复计算。配装使用自动遗器时，合法主副词条自动计入面板。

页面顶部的“真实敌人：三只虚卒·掠夺者”保留四名队员，替换敌方；点击“运行自动战斗”查看新结果。该场景采用 Lv.90 基础敌人面板，无混沌等关卡额外倍率。参考队可能在敌人出手前取胜；要验收受击、护盾和回血，可在敌方面板中增加生命，或降低我方初始生命，重新运行。

当前 4.6 数据库的 62 套遗器（外圈 101—134、内圈 301—328）均已接入参数与事件规则；条件、来源核验和展示口径见[遗器全量与分段伤害验收](遗器全量与分段伤害验收.md)。其中 133/134 按数据库文案实现，固定版本触发脚本仍待交叉核验。另接入舞！舞！舞！、记忆中的模样、与行星相会、唯有沉默、永远的迷境饭。

## 严格模式如何拒绝缺失规则

- 未登记的真实角色、光锥被动、套装和真实敌人行为在运行前给出具体原因。单纯删除 `unsupported` 文字无法使未实现角色通过。
- 已登记角色的技能等级参数、行迹 / 星魂参数、倍率、分段和能量成本会对照固定版本检查；修改 JSON 后与登记机制不符会被拒绝。
- 战技点上限按角色规则自动计算。默认队伍为九点；花火 E4 会再加一点。
- 缺少受击回能、可能发生但没有规则的击破、无效辅助目标或资源配置，在运行前拒绝。
- 自定义训练敌人属于显式输入规则；严格通过表示输入规则完整、可执行，不表示任意命名的训练敌人已经复刻游戏 Boss。

## 建议验收

1. 保持严格模式勾选，运行默认队伍，查看四人贡献、专武来源和龙灵行动条。
2. 从日志选择奇袭首段完成处再单步，核对首段不耗点、后段耗两点，两段均恢复原生能量，并且爵位覆盖两段；奇袭首段不占五次主动限制。
3. 点击 Archer、龙灵关联队员与敌人，查看当时的生命、能量、护盾、韧性、资源、效果数值 / 来源 / 剩余回合 / 条件。拖回开场后累计伤害归零；结束时与整场统计一致。
4. 分别更换三名辅助目标，切换花火原版 / 强化版并应用，再运行。原结果应标为过期，不会随编辑悄悄改变。
5. 切换三虚卒场景，按需要提高敌方生命，核对敌人攻击、相邻站位、盾吸收和受击回能。暗色与浅色主题均可使用。
6. 导出配置和日志。相同配置与随机种子应产生相同结果；有实际游戏记录时，在“游戏实测对照”输入锚点定位首次差异。

## 来源与验证边界

数值来自已有 4.6 数据库；动作顺序、动画权重、原生回能比例与条件读取自 [DimbreathBot/TurnBasedGameData 的固定正式版本](https://github.com/DimbreathBot/TurnBasedGameData/tree/312b4597691e0a29cf9828a15b592757dba86949)。使用的数据文件 URL、SHA-256、提取的分段 / 仇恨 / 击破基数 / 敌人事实保存在 `data/combat/source_evidence.json`。实现由本项目编写，未复制第三方模拟器代码。数据出处与权利说明见 `THIRD_PARTY_NOTICES.md`。

`npm test`：原有检查 479 条、配装与四人模式检查 63 项、回放检查 17 项、严格队伍检查 64 项、公开对照 18 项、场景与配装检查 19 项、更新器检查 8 项通过。严格专项覆盖同回合连续技能、免费 / 付费奇袭、附加伤害归属、召唤物、星魂组合、专武各叠影、击破和敌方行为。缓存存在时可用 `python _scripts/build_strict_evidence.py --check` 检查提取文件是否与本地固定来源一致。

**公开基础伤害与规则对照 18 项通过；该四人队伍完整实战录像对拍仍未完成。** 用户自行录入的伤害锚点文件仍为空，此项仍跳过。 本版支持上述四人和登记规则的单波次或多波次场景；尚不支持全角色、全部光锥、特定 Boss 阶段与场景专属机制，也不包含全部属性击破与控制。自动行动采用配置的确定策略，不等于游戏客户端原生自动战斗 AI。这些范围不能由本轮回归测试推导为已完成；当前可用于这支队伍的规则与行动轴验收，不能承诺所有实战结果已经逐项对拍一致。
